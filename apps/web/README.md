# @bakesbymom/web

The Bakes by Mom website: a home bakery in Panipat, Haryana, where everything is 100% eggless and orders go through WhatsApp. It's built only from [`@bakesbymom/ui`](../../packages/ui) and the board specs in [`design/board/sections/`](../../design/board/sections). The content, categories, photos and ordering flow come from the old site (bakesbymom.vercel.app), and the paths match it, so old links keep working.

| Path                  | Page                                                                                                                                                                                                                                                             |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/`                   | Home: seven bands, from the striped hero to the sideways How to order ride ([the home page, band by band](#the-home-page-band-by-band))                                                                                                                          |
| `/catalog`            | The Cakes category: every cake in the catalog database, shelved by occasion, each on a ticket card with its weight and price in one capsule. `?occasion=anniversary` opens one shelf, and `?flavour=biscoff` shows every cake in that flavour                    |
| `/catalog/<cake>`     | One cake: photos, price, and an order builder (size, flavour, add-ons, message, date, time, pickup or delivery) that opens WhatsApp                                                                                                                              |
| `/shop`               | **Cakes & Treats**, the one place to order from and the nav's single link for cakes and treats: a collage hero, every category as a sticker card on a caramel shelf (cakes first, each opening its own page), a custom order on WhatsApp, and how an order works |
| `/shop/<type>`        | Brownies, cookies, jar cakes, dry cakes, cupcakes, bento cakes or combos: the same page for each (`TreatShowcase.tsx`), a hero in the category's own color with a fan of photos, then its treats as cards to customise and order                                 |
| `/shop/<type>/<item>` | One treat and its order builder (quantity, flour for cookies, extras, date, time)                                                                                                                                                                                |
| `/about`              | Our story, short: a letter from Mom, her cakes on a silver tray with who each was for, and her promises as a menu card                                                                                                                                           |
| `/links`              | The Instagram link-in-bio page (pin 08)                                                                                                                                                                                                                          |

```bash
npm run web        # at the repo root: builds the packages, then starts the site at http://localhost:5173
npm run build:web  # production build into apps/web/dist
npm test -w @bakesbymom/web
```

## Where things live

| `src/content/samples.tsx`     | Sample content for Storybook-only demos; nothing in it is on the website                                                                           |
| `src/sections/blocks.tsx`     | Every page section. Storybook's _Sections_ and _Pages_ stories import these same files                                                             |
| `src/sections/story.tsx`      | Our story: a letter from Mom, her cakes on a tray, her promises as a menu card (styles in `story.css`)                                             |

| `src/sections/reels.tsx`      | The Instagram reels in the hero's card; the list of reels is in `src/content/instagram.ts`                                                         |
| `src/sections/fx.tsx`         | The big scroll scenes: the flavour deck, the curved sign-off (off the home page, kept) and the footer word                                         |
| `src/sections/order-rail.tsx` | How to order as a ride sideways: the section pins and its panels slide past (styles in `order-rail.css`)                                           |
| `src/fx/`                     | The motion layer: GSAP and ScrollTrigger with Lenis, shared effects, sprinkles (spec: [`motion.md`](../../design/board/sections/motion.md))        |

## Keeping it up to date

- **Cakes.** The cakes come only from the Cloudflare D1 database the old site uses, so add or change them in the old site's admin page and the change shows up here on the next page load; nothing about them is kept in this repo. The site reads the database through the old site's Worker (`bakesbymom.snehagupta.workers.dev`): `vercel.json` rewrites `/api` to it, and `npm run web` and Storybook proxy it. Photos are shown the way the old site shows them: the cut-outs in the R2 bucket, except the cakes re-shot against a styled background (`public/photos/restaged`), with small covers for the shelves in `public/photos/thumbs`. Both folders and their lists in `catalog.ts` come from the old site's repo; copy new ones over when it adds more.
- **Photos of the treats.** The cookies have a photo each, chosen by the bakery (`public/photos/cookies`, listed in its README and set as `photo` on each cookie in `treats.ts`). The other treat types use stock photos from Unsplash (`public/stock`, credits in `public/stock/CREDITS.md`), and their pages say "Photo for reference". On the home page the hero, the about card and the Cakes & Treats wheel's cakes card show our own cakes (`heroCake`, `aboutCake`, `occasionsCake`), and the wheel's cookies card our own cookies. Swap in photos of your own boxes the same way: a `photo` on the treat, a type's photo in `ownTreatPhotos` (the wheel reads it through `categoryPhoto`), or change `stock` and `treatArt` in `src/content/index.ts`. The flavours have no stock photos: each is shown on one of our cakes (below).
- **Flavours.** Add or remove one in `cakeFlavours` (`bakery.ts`), with what's inside it and the cake it's shown on in `flavours` (`index.ts`: the cake's slug in the catalog; a cut-out suits the card best, and if that cake leaves the catalog the card takes another one of ours) and its card's colors and the ground it brings (`ground`, the colour the deck turns to as that card flies in) in `looks` (`sections/fx.tsx`). The deck, every cake's flavour picker, the catalog's `?flavour=` filter and the "N flavours" chip in How to order follow the list.
- **Collage art and stickers.** The Cakes & Treats and cakes pages and the order steps are collages in the style of the board pins (`src/collage`): bakes cut out as die-cut stickers, halftone prints in cherry ink, stamp-framed photos, scalloped badges, tape and gift tags. The stickers and halftones in `public/collage` are made from the stock photos by `python scripts/collage.py` (Pillow and NumPy); run it again when a source photo changes. A photo on a plain background cuts out cleanly; one whose background can't be cut away becomes a rounded photo sticker instead (`photo_sticker`, as for the bento cakes). Our story's tray, the dry cakes and the cupcakes on the Cakes & Treats shelf use painted dessert stickers (`public/collage/paint-*.webp`), generated in Canva Dream Lab and cut out once.
- **Phones.** The motion is tuned to stay smooth on a phone: scroll scenes ignore the address bar sliding in and out, looping decorations pause while their band is off the screen, anything that follows the scroll takes its position from one shared feed (`onScroll` in `motion.ts`) and measures the page only when it changes size, and a standing `will-change` is kept only for what moves every frame (the How to order strip and its donut, and the cursor label on a mouse). Sprinkles burst on a tap, not on the touch that starts a scroll. Check a change on a real iPhone too: Safari lays out a few things differently from Chrome (a percentage height inside a flexible box, for one, which left the flavour photos blank once).
- **Instagram reels.** The hero's card plays the bakery's reels one at a time, through the embed page Instagram serves. Add or remove one in `reels` (`src/content/instagram.ts`), keeping only the code from the reel's link (the part after `/reel/`), never the tracking parameters a shared link carries. Only the reel on screen loads with the page; the next one loads once a visitor reaches for the reels.
- **Not wired up.** Ordering is WhatsApp-only, by design: nothing is sent from the site. The Ask Mom assistant answers from the catalog and hands off to WhatsApp.

Deployed on Vercel from the repo root, as the root README describes; a project whose root directory is this folder works too, through `vercel.json` here.

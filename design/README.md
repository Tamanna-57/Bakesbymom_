# Design

The Bakes by Mom design system is built from the **[bakesbymom Pinterest board](./board/README.md)**: 16 pins, analysed one by one, with a palette measured from them, the best reference picked for each website section, and a brand kit.

| | Where |
|---|---|
| Board index, section picks and counts | [board/README.md](./board/README.md) |
| Palette | [board/palette.md](./board/palette.md) |
| One analysis per pin | [board/pins/](./board/pins) |
| One spec per website section | [board/sections/](./board/sections) |
| Brand kit | [board/brand-kit.md](./board/brand-kit.md) |
| Pin images | [`pinterest/board/`](../pinterest/board) |

The system itself lives in [`packages/`](../packages) (tokens and React components) and is documented in Storybook (`npm run storybook`).

## Other files in this folder

`DESIGN.md` to `DESIGN-9.md` are the earlier web style references added to the repo before the board existed. They're kept for context, but the board is now the only source for decisions.

# Bakes by Mom Design System

> **"Mom's recipe notebook, open on the counter of a little pink-and-blue bake shop."**

Everything in this Storybook comes from one place: the 16 pins on the [bakesbymom Pinterest board](https://in.pinterest.com/nuttychip/bakesbymom/). The palette was measured from the pins, every section was picked from the pin that does it best, and each story links back to its pins.

| --- | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 📌  | **The board**: all 16 pins, each analysed for layout, sections, components, color and type                                                    | _Board / Moodboard_ · [`design/board/pins/`](https://github.com/Tamanna-57/Bakesbymom_/tree/main/design/board/pins)        |

## Principles

1. **Beige paper, cocoa ink.** Pages sit on beige (`--bbm-color-bg-canvas`) and text is cocoa brown, never black. Baby blue and baby pink carry the bands; cherry is the accent.
2. **One cherry action.** Deep cherry (`cherry-700`) is the filled button color. The bright cherry band (`cherry-500`) appears once per page.
3. **Stickers hold the pastels together.** Objects get a 1.5px cocoa outline and, when lifted, a hard offset shadow with no blur, like pins 01, 02 and 05.
4. **Handmade at the edges, calm in the middle.** Stripes, grid paper, gingham, dots, scallops and torn edges frame sections and photos. Paragraphs, prices and forms stay on plain paper.
5. **A notebook voice.** Fraunces for headlines and prices, DM Sans for reading, Pinyon Script for one word or Mom's signature, Caveat for handwritten notes, Cherry Bomb One for one bubble word.
6. **Sweet for everyone.** Approved text pairings pass WCAG AA (tested in CI), targets are 44px or more, focus is always visible, and motion stops for people who prefer reduced motion.

## Using the system

```bash
npm install            # in this repo (npm workspaces)
npm run storybook      # builds tokens, then opens Storybook on :6006
npm run check          # format, build, typecheck, tests, static Storybook
```

```tsx
// In an app
import '@bakesbymom/ui/fonts.css'; // Fraunces, DM Sans, Pinyon Script, Caveat, Cherry Bomb One
import '@bakesbymom/ui/styles.css'; // tokens + component styles
import { Button, ProductCard } from '@bakesbymom/ui';

// …and add className="bbm-theme" to <body> for the canvas, ink and body type.
```

Prefer CSS variables? Import `@bakesbymom/tokens/css` and use `var(--bbm-color-bg-canvas)`. Using Tailwind v4? Import `@bakesbymom/tokens/tailwind.css` for `bg-canvas`, `bg-blue-200`, `text-cherry-700`, `font-display`, `font-hand` and `shadow-sticker-md`.

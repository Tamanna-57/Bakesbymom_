# Patterns & Decoration

The board's printed patterns, paper edges and doodles. They are what make a Bakes by Mom page recognizable. All of them are pure CSS or SVG generated from tokens, so they recolor with any `tone`.

**Rule:** decoration frames content. Patterns sit behind photos, labels and edges, never behind paragraphs.

## Helpers

| Class                 | Effect                                                                   |
| --------------------- | ------------------------------------------------------------------------ |
| `.bbm-script-word`    | Swaps one word into Pinyon Script inside a serif line                    |
| `.bbm-squiggle`       | Hand-drawn underline in the brand color (pin 03)                         |
| `.bbm-sticker-cutout` | White die-cut halo plus a hard shadow around transparent photos (pin 07) |
| `.bbm-seam`           | Places a sticker straddling the top edge of a section (pin 11)           |
| `.bbm-font-soft`      | Puffy retro Fraunces for the logo and playful moments                    |

# Typography

Four families, each with one job. All are free Google Fonts (SIL OFL), loaded by `@bakesbymom/ui/fonts.css`.

<FontFamilies />

## Type scale

Display and heading sizes are **fluid**: they scale smoothly between the phone and desktop sizes with `clamp()`. Use the classes (`.bbm-text-display-xl`) or the variables (`--bbm-text-display-xl-size`, `-line-height`, `-tracking`, `-weight`, `-family`).

<TypeScale />

## Fraunces softness

Fraunces is a variable font with `SOFT` and `WONK` axes, so one family covers several looks:

| Token                          | Value                  | Use                                                                     |
| ------------------------------ | ---------------------- | ----------------------------------------------------------------------- |
| `--bbm-font-variation-display` | `"SOFT" 50, "WONK" 0`  | Default for headings                                                    |
| `--bbm-font-variation-soft`    | `"SOFT" 100, "WONK" 1` | Puffy, Cooper-style: logo, price tags, promo posters (`.bbm-font-soft`) |
| `--bbm-font-variation-crisp`   | `"SOFT" 0, "WONK" 0`   | Sharper patisserie caps: marquees, editorial lines                      |

## Script, sparingly

Pinyon Script is an accent: one word in a headline (`<em>` inside `SectionHeading` and `Hero` titles), a second line under a title, captions on polaroids, and Mom's signature. Never use it for buttons, labels, body copy or anything under 28px.

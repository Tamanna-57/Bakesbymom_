# Moodboard

These are the Pinterest pins behind the system. Each title opens its full Style Reference in [`design/pinterest/`](https://github.com/Tamanna-57/Bakesbymom_/tree/main/design/pinterest), with measured colors, type identifications, components, do's and don'ts, and what Bakes by Mom took from it.

**Primary** references shaped the system directly. **Strong** ones contributed specific components. **Supporting** ones (mostly posters) inform social templates.

The nine web style references (Lamanna, Pa'lais, Apron, Beautiful™, Alison Roman, Mr. Pops, bella, Ko-fi, Monte) are documented in [`design/README.md`](https://github.com/Tamanna-57/Bakesbymom_/blob/main/design/README.md).
